# Criminal Risk Assessment – ODK XLSForm

## Assignment

This project is my implementation of Assignment 2 for developing an ODK XLSForm based on the provided Criminal Risk Assessment Request PDF.

## Understanding

The PDF was analysed to identify its fields, choices, required fields, validation requirements, conditional fields, and informational sections. These requirements were then represented using the XLSForm structure.

## XLSForm Structure

The workbook contains three sheets:

- **survey** – Defines the main form structure, field types, names, labels, requirements, constraints, and conditional logic.
- **choices** – Defines the predefined options used by select-one and select-multiple questions.
- **settings** – Contains the form title, unique form ID, and version.

## Validation

The XLSForm was tested using the ODK XLSForm tool and successfully validated without errors.

The generated form was also tested for:

- Required fields
- Identification selection validation
- Conditional fields
- Predefined choices
- Consent-related behaviour
